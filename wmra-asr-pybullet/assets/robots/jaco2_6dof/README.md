# Aset robot Kinova JACO Gen 2

Berkas `j2s6s300.urdf` dan seluruh mesh/material pendukung **tidak ada di ZIP yang diterima**. Folder ini adalah lokasi default setelah mendapat aset dari sumber yang memiliki izin penggunaan dan redistribusi sesuai lisensinya.

Jangan membuat model URDF kosong/palsu. Struktur relatif path dari URDF ke mesh harus dipertahankan. Jika pengguna memiliki URDF di lokasi lain, atur environment variable `WMRA_JACO_URDF` sesuai petunjuk README.
